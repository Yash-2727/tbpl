THE BLUE PAPER LAB – Aquarium 7-in-1 Strip Analysis
Version 1.2 – Automatic Seven-Pad Detection

Base: approved Version 1.1 Image Verification ZIP.

Changes:
- Automatic detection of seven aligned pad regions after image verification.
- Automatic numbering and fixed mapping: 1 Nitrate, 2 Nitrite, 3 Chlorine, 4 GH, 5 TA, 6 KH, 7 pH.
- Automatic centre-colour sampling and chart matching; technician no longer clicks pad locations.
- Numbered overlay markers and colour/result review displayed per strip.
- Fail-closed behaviour if seven pads cannot be located with sufficient geometric consistency.

Limitations:
This is a classical browser-side computer-vision heuristic, not a trained AI object detector. The confidence value is a geometric consistency score, not a statistically calibrated probability. Inspect markers and captured colours. Colour chart swatches remain approximate and require calibration.


VERSION 1.2.1 – CHART COMPARISON FIX
- Fixed the missing completion call after automatic pad sampling.
- Once all three replicate strips have seven pad matches, the application
  renders the seven-parameter concentration comparison table, per-strip
  values, median and replicate range.
- Each captured pad colour is compared against the corresponding parameter's
  existing Aquarium 7-in-1 reference levels using nearest-RGB matching.
- Preserved the interface, automatic pad detection, image verification,
  three-strip workflow, chart editor, records and report generation.
- Reference HEX colours remain approximate digitizations from bottle-chart
  photographs and require controlled calibration. Results are estimates,
  not validated analytical measurements.

VERSION 1.3 – CIEDE2000 COLOUR MATCHING
- Replaced the nearest-RGB decision rule with CIEDE2000 (Delta E 2000).
- Captured sRGB pad colours and reference HEX colours are converted to CIE Lab
  using the sRGB/D65/2-degree observer conversion.
- Each measured pad is compared with every reference level for its own
  parameter; the smallest Delta E 2000 selects the chart category.
- Per-pad display includes Delta E 2000 and legacy RGB Euclidean distance.
- RGB distance is diagnostic only and no longer determines the selected level.
- Image verification, automatic pad detection, chart, three-strip workflow,
  median/range, records and reports remain unchanged.
- Reference HEX colours remain approximate digitizations from bottle photos.
  Delta E 2000 does not fix inaccurate references, lighting, camera white
  balance or strip timing. Controlled calibration and validation remain needed.
