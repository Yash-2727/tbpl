REFERENCE / 04

How this prototype works

Practical operating notes and limitations.

Recommended workflow

  1. Create or verify a manufacturer and model profile in Reference charts.
  2. Enter sample details and select the matching profile.
  3. Upload three separate reacted-strip images. Each image passes through the automatic strip-pattern and focus/exposure gate before analysis is enabled.
  4. Run analysis. The prototype automatically detects seven aligned pad regions, samples the central ROI using median channel values and displays numbered markers for technician review. If all seven cannot be detected confidently, analysis is blocked.
  5. Review pad colours, quality warnings and nearest chart matches and the top-three ΔE00 diagnostics. Correct pad positions or concentrations when needed.
  6. Save the record and download the report.

Colour matching approach

For each pad, the app samples the central region using median RGB channel values to reduce the influence of glare, edge shadows and isolated pixels. It converts the measured and reference sRGB colours to CIELAB (D65/2°), ranks all chart swatches using CIEDE2000 (ΔE00), and displays the three closest matches, best/second-best score and score gap. The score gap is diagnostic only; no universal confidence threshold is claimed. Different cameras, lighting, white balance, strip chemistry, reaction time and pad ageing can change the apparent colour.

Validation required before deployment

  • Verify the digitized chart colours against controlled reference images and the package instructions.
  • Build a validation dataset using known concentrations and reference laboratory methods.
  • Determine repeatability, bias, detection limits and uncertainty for each parameter.
  • Do not use this prototype to certify drinking-water safety or replace BIS/NABL-aligned methods.
  • Local browser storage is not a secure multi-user database and does not sync between devices.
